# 🚀 Taskify - Todo List App

Taskify is a modern and responsive Todo List web application built using **React**, **React Router**, and **Tailwind CSS**.  
It includes dark/light mode, responsive navigation, and clean UI design.

---

## ✨ Features

- 📝 Add, manage, and organize tasks (UI ready for logic expansion)
- 🌙 Dark / Light mode toggle
- 📱 Fully responsive design (mobile + desktop)
- 🔗 React Router navigation (Home, Features, Login, Sign Up)
- 🎨 Modern UI using Tailwind CSS
- ⚡ Fast and lightweight (Vite powered)

---

## 🛠️ Tech Stack

- React.js
- React Router DOM
- Tailwind CSS
- Vite
